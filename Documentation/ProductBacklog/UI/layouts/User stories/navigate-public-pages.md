# Navigate public pages

As a visitor, I want to use public navigation and the landing-page account actions so that I can explore Recipe Manager or open sign-in and registration.

## Behavior

- The base layout presents Home and Features navigation.
- The landing page's Sign in and Register actions open the shared authentication dialog in the corresponding form mode.
- The public header has no separate authentication links.

## Acceptance criteria

- **AC-01:** The base layout presents Home and Features navigation; the landing page's Sign in and Register actions open the shared authentication dialog in the corresponding form mode.

## Traceability

- Acceptance criteria: AC-01
- Domain rules: R-01, R-04
